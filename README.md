# Swachh Score – Cleanliness Dashboard

## Overview
Swachh Score is a data-driven dashboard built to monitor and analyze cleanliness levels using real-time insights. The project was developed as part of the 1M1B Green Internship focusing on sustainability use cases.

## Features
- Interactive dashboard using Streamlit  
- Data visualization for cleanliness trends  
- Real-time insights generation  
- Simple and user-friendly interface  

## Tech Stack
- Python  
- Streamlit  
- Pandas  
- Matplotlib  

## How it Works
- Data is processed and cleaned using Python  
- Visualizations are generated to represent cleanliness scores  
- Dashboard displays trends and insights in an interactive format
